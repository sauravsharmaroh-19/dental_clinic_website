DENTAL CLINICS WEBSITE — HTML + CSS

Files:
- index.html       Home / lead-generation landing page
- about.html       About the clinic
- services.html    Treatments overview
- contact.html     Contact and appointment enquiry
- style.css        Shared styling for all pages

How to preview:
1. Extract this folder.
2. Double-click index.html, or open the folder in VS Code and use Live Server.
3. Use the navigation to move between separate pages.

Before publishing:
- Replace the sample phone number, email, address, hours and clinic name as needed.
- The patient feedback blocks on the homepage are placeholders; replace them with genuine reviews only with permission.
- Remote Unsplash images and Google Fonts require an internet connection.
- The contact form currently uses mailto as a simple demo. It is not a secure, production-ready appointment booking system. Connect a suitable form backend/plugin and test submissions.
- Confirm all treatments, claims, clinician credentials, opening hours and contact details are accurate for the actual clinic.
